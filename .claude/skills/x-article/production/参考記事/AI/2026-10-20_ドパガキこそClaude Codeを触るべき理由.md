ドパガキこそClaude Codeを触るべき理由

トイレ中も風呂中もスマホを手放せないスマホ中毒者の皆さん、Claude Codeを触ってください。

SNSやゲームなどの手軽な刺激なんかよりも、Claude Codeを使えば脳汁ダダ漏れの真のドパガキになれることを約束いたします。

実はClaude Codeは、普段から何かしら刺激を欲していたり、日常的にSNSを見まくってる方が1番相性がいいです。

僕自身、ずーっとスマホでクソゲーしたりXやショート動画を無限に見続ける生活をしてましたが、今では「Claude Codeが何やってくれたか?」「数字が伸びているか?」「稼いでくれてるか?」てことばっかり心を持ってかれており、ゲームやSNSじゃ刺激が全然足りなくなってしまいました。

「Claude Codeなんてエンジニア向けの道具でしょ」って思うかもしれませんが、むしろ逆です。僕からすると、ただの脳汁量産ツールと化しています。じゃあ具体的に何がそんなに魅力的なのかこの記事でお伝えしたいと思います。

### 理由1:ゲーム感覚でビジネスが構築できて、勝手に回ってお金が入る

ゲームって大人になっても面白いですよね〜。大人になった今でも時々時間を忘れるくらいやってしまいます。頑張ってステージクリアして、経験値やゴールドを獲得した時の快感は堪らないです。

じゃあもし、これがビジネスでできるのだとしたら、もっとキモチイと思いませんか?

数十分か1時間くらいちょろっとやって、ビジネスが1つずつ構築されていって、数字が伸びて、リアルのお金が入ってくる。

「いやー、でも実際のビジネスはゲームと違って全然進まないから時間かかっちゃうよー」て思うかもしれません。実際、ビジネスなんてゲームの100倍くらい進むスピードが遅いんですよね。

ただただ社内のメンバーに報告するためだけに、プレゼン資料を1日かけて作り込んだり、LP作るのに数日かかったり、新規事業を作るのに数ヶ月かかったり、、、という感じで、ステージクリアして報酬を得るまでにゲームの何百倍も時間がかかってしまいます、、、だからつまらない。面白くない。キモチヨクない。

でも、Claude Codeという最強AIを使えば違います。

- 数時間でビジネスを構築して
- 1日10分でビジネスを回して
- ポンポン数値が上がっていく
- 再生数が伸びていく
- ポンポン売れていく
- ポンポンお金が入っていく……

みたいなことができちゃうんです。

今までなんとなく刺激が欲しくてSNSやゲームをしていたような時間が、どんどん「Claude Codeがやってくれてるあれ、数字伸びてるかな?収益入ってるかな?」という確認でワクワクする日常になります。

実際僕は今、Claude Codeでやってるビジネスの1つとして、TikTokを90%自動化して1日10分で運用しているんですが、常にそういう状態です。

正直、僕には動画編集スキルや動画作成のスキルは1ミリもありません。基礎も何もないし、どんなソフトやツールをどう使えばいいのか、他の人がどうしてるのかすら全く分からないです。

でも、Claude Codeを活用してたった10分でこんな動画を作ってアフィリエイトを行いどんどんお金が増えてます。しかもこれ、初めてClaude Codeで作った動画なんです。初投稿にして15個も売れてしまいました、、しかも動画は1度上げるとずっと回って売れ続けるので、毎日売上の通知が止まりません。

Claude Code にただ指示するだけで、10分作業して動画を作れて投稿できる。そういう感じでポンポン動画を量産しては常に数字を見て、「これ伸びてるかな?」「うおーめちゃくちゃ伸びた!!」「これもっとこうすりゃいけんじゃね??」とか、「めちゃめちゃ売れてるーー!!!」とか、そういう快感がたまらないです。

実際に自分のお金につながるので、その辺のゲームだったりSNSなんてものとは比べものにならないほどキモチイイし、面白いです。

### 理由2:SNSを普段から見まくってるから、伸びる投稿が何かという感覚が養われてる

Claude Codeで自動で行うマネタイズやビジネスで、特に相性がいいのはSNSです。じゃあSNS運用でどういうスキルが一番重要なのかというと、いかに見る人の気持ちが分かっているかどうかです。

結局マーケティングの本質みたいなところってそこに尽きるので、どういう動画だったりどういう投稿をすれば人が見たいと思えるか、ということを分かっているかどうかが全てです。

でもそれって普段からめちゃくちゃSNSを見ていないと養われないものなんですが、この一番大変な部分を、普段からSNSを見まくっている人は皆さんは熟知しているんです。

だからこそ、本当にいい投稿、人に見てもらえる投稿というのが作りやすい。なのでSNSを活用してアフィリエイトを行えば、自分で商品などを作らなくても、勝手にどんどんお金が入る仕組みを作れてしまいます。

また、僕自身Claude Codeを使ってX、Threads、TikTokなど全部試してきましたが、1番相性がいいのは圧倒的にTikTokです。実はテキスト系のSNSってコミュニケーションそのものなんで、人間が1番違和感を感じやすいのでAI感があるとすぐに煙たがられるのでかなり難易度が高いんですよね。だからClaude Code×TikTokが1番アツいです。

### 最後に

てなわけで、刺激大好きなドパガキの皆さんはClaude Codeを使ってTikTokをやることをおすすめいたします。シンプルに、SNSやゲームしてても何にも繋がらないし、そんなことよりもやればやるほどお金が増えていく方がメリットだらけだし、もっと脳汁出るしやらない理由ないですよね。
