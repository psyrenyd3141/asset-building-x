# 参考記事フォルダ

記事を書く前に読み込ませる、伸びている他アカウントのX記事を保存する場所。

- `𝕏記事作成ナレッジ.md` の手順に従い、最低5本入れる
- **URLだけでなく、できれば本文も保存する**。文章をコピーするためではなく、タイトル・構成・保存される理由を分析するために使う
- 1本ごとに次を書く: URL、表示回数、いいね数、ブックマーク数、引用数、取得日
- ジャンルに近く、ブックマーク率が高いものを優先する(0.1〜0.2%で「保存されている」、0.2%以上で「本文の構成を詳しく見る候補」)。**さらに、X広告収益・保存・リストイン・販売のうち、今回の記事と同じ目的の記事を優先する**(目的ごとに重視する指標が違う。`kiji-nouhau.md`の「指標の見方」参照)
- 動画つきの引用で表示が伸びた記事は、記事本文の実力と分けて扱う
- ファイル名は分かりやすく(例: `2026-10-20_AI系_タイトル.md`)
