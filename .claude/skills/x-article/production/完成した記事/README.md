# 完成した記事フォルダ

公開した(または公開予定の)記事を `YYYY-MM-DD_テーマ/` ごとに保存する場所。**AIが1記事ごとにこの日付・テーマのフォルダを作り、以下を保存する**(「𝕏記事作成ナレッジ.md」参照):

- `タイトル.md`(本人が決めたタイトルと、参考にしたタイトル)
- `参考記事の分析.md`
- `構成案.md`
- `article.md`(本文)
- `引用.md`(自己引用5本)
- `確認結果.md`(公開前の確認結果)

記事を公開したら、`確認結果.md`または記事フォルダ内に公開後の数字(表示回数・ブックマーク数・ブックマーク率・リストイン数)を追記する。当たった理由と外した理由は `𝕏記事作成ナレッジ.md` または `../自分の情報.md` にフィードバックし、次の記事に活かす。
